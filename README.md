## 貯蓄目標ビジュアルトラッカー

複数の貯蓄ゴールを並行管理し、コインアニメーションと複利グラフでモチベーションを維持する貯蓄管理ツール。

### 機能
- ゴール登録モーダル: ゴール名・目標金額・毎月積立額・期待利率・現在貯金額・絵文字アイコン
- 複数ゴール管理（最大6件・カード表示）
- 貯金箱アニメーション: 達成率に応じてコインが溜まる（CSS animation）
- 達成グラフ（Canvas 2D 折れ線）: 複利込み残高推移・目標ライン表示
- 目標達成月を計算して各カードに表示
- ゴール間の優先度ドラッグソート（HTML5 Drag and Drop API）
- localStorage: 全ゴールデータ永続保存

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- Canvas 2D API（複利成長グラフ・グラデーション塗り）
- HTML5 Drag and Drop API（ゴール優先度ソート）
- localStorage（JSON 全ゴール保存）
- CSS animation（コインドロップ）
